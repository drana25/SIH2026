# Transit & Tourism Trust Protocol

## Description
This project is a transit and tourism trust protocol application designed to help users compare route fares and view heritage guides. It's built with HTML, JavaScript, CSS, and integrated with Firebase for real-time data.

## Setup Instructions
1. **Fork the Repository**  
   Each teammate should fork the repository to their own GitHub account.

2. **Clone the Forked Repository**  
   After forking, clone the repository from your own account using HTTPS:  
   \`\`\`
   git clone https://github.com/yourusername/your-forked-repo.git
   \`\`\`

3. **Navigate to the Project Directory**  
   \`\`\`
   cd your-project-directory
   \`\`\`

4. **Install Dependencies**  
   Install the necessary npm packages:  
   \`\`\`
   npm install
   \`\`\`

5. **Firebase Configuration**  
   A teammate will generate the Firebase keys. Once they’re available, add them to a `.env` file or the appropriate configuration.

6. **Run the Project**  
   - Option 1: Double-click the `start_varada.bat` file to launch the local server.  
   - Option 2: Open the terminal in VS Code and run the Node.js server command (e.g., \`node server.js\`).
